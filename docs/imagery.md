# Demo artwork and owned photos

Virasat does not download product photography. Every seeded product image and craft cover is generated locally with Pillow from original drawing code in `catalog/art.py`. The art is deliberately illustrative, so the demo never presents a stock photo as a real artisan's work.

## What the generator produces

| Asset | Size | Format | Limit | Location |
| --- | --- | --- | --- | --- |
| Product image | 1200 x 1500 (4:5) | Progressive JPEG | 250 KB | `media/products/demo/<product-slug>.jpg` |
| Craft cover | 800 x 800 | Progressive JPEG | 180 KB | `media/crafts/<craft-slug>.jpg` |

All twenty product images and nine craft covers are distinct. The generator uses the product slug and craft slug as its random seed. Running the same seed again produces the same pixels, while a different slug changes the palette, motif placement and composition.

## Craft-specific drawing

Each tradition has its own palette and motif renderer:

| Craft | Visual language |
| --- | --- |
| Madhubani | Fine double borders, lotus rosettes, fish, sun motifs and ochre paper |
| Pattachitra | Scalloped frame, concentric medallion and warm red, black and yellow |
| Bagru block print | Repeating buta motifs with a slight offset that suggests hand-print registration |
| Bandhani | Deep madder ground, tied dots, fine rings and yellow border bands |
| Phulkari | Dense geometric diamonds and darning stitches in floss colours |
| Kantha | Soft patchwork blocks crossed by rows of running stitches |
| Channapatna toys | Turned wooden forms with bright lacquer bands and glossy highlights |
| Dhokra | Dark metal ground, brass spirals and small tribal figure silhouettes |
| Blue pottery | Cobalt and turquoise florals, leaves and dots on a pale glazed ground |

The item silhouette comes from the product title: wall hanging, bookmark set, scroll, cushion, tote, bowl, tile pair, pouch, scarf, stole, dupatta, elephant, spinning top or rattle. Every rendered scene also gets a textured paper backdrop, contact shadow, soft shading, a thin outline and a light vignette.

The unused-image placeholder at `static/img/placeholder.svg` and the repeating hero pattern at `static/img/hero-pattern.svg` use the same craft vocabulary.

## Regenerate demo art

Normal seeding creates missing files but never overwrites existing media:

```bash
python manage.py seed_demo
```

Force a rebuild of all twenty product images and nine covers:

```bash
python manage.py seed_demo --refresh-images
```

The command reports how many files it generated. Existing accounts, products, orders and edited text are not reset.

## Use your own photos in the demo

Only use photographs you own or have explicit permission to publish. The seed command never downloads anything.

1. Choose the product you want to replace and find its slug in the table below.
2. Put a photo at `media/seed_photos/<product-slug>.jpg`. The supported extensions are `.jpg`, `.jpeg`, `.png` and `.webp`.
3. Run `python manage.py seed_demo --refresh-images`.
4. The command crops the photo to 4:5, resizes it to 1200 x 1500, converts it to JPEG and keeps it under 250 KB. It then assigns the usual `media/products/demo/` path to the product.

## Tests

`catalog/tests_art.py` checks that:

- Every craft renderer writes a valid 1200 x 1500 JPEG below 250 KB.
- Every craft cover is a distinct 800 x 800 JPEG below 180 KB.
- The same slug is byte-for-byte reproducible.
- Two different slugs in one craft produce different artwork.
- An owned photo is cropped to 4:5 and compressed below 250 KB.
- Seed titles map to the intended item silhouette.

The media directory is ignored by Git. The generator code, tests and SVG assets are committed.
